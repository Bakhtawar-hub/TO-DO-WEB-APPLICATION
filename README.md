# ✨ Neon Futuristic Flask Todo Web App

This is a **Futuristic Neon Styled Todo List Web Application** made using **Flask (Python)** and **SQLite**.  
The UI includes **animated glowing effects, smooth transitions, task priority system, and Done/To-Do toggle button**.

---

## 🚀 Features

| Feature | Description |
|--------|-------------|
| ➕ Add Tasks | Add title, description & select priority |
| ✏ Edit Tasks | Update any task details anytime |
| ❌ Delete Tasks | Remove tasks permanently |
| ✅ Mark as Done | Click to toggle **Done / To-Do** state |
| ⭐ Priority Levels | High / Medium / Low with badges |
| 🎨 Neon Animation UI | Modern futuristic glowing layout |
| ⚡ Smooth Slide Animations | Tasks appear with motion fade-in |
| 📱 Fully Responsive | Works on laptop + mobile |

---

## 🧱 Technologies Used

| Component | Tech |
